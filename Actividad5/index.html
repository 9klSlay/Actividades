Comparación de If y Else If

Comparación entre dos formas de evaluar la variable a = 950

Script 1

Diferencia:
Utiliza varios if independientes. Cada condición se evalúa por separado.
a = 950 if (a < 576) { console.log("xs") } if (a < 768) { console.log("sm") } if (a < 962) { console.log("md") } else { console.log("xl") }
Presiona el botón...

Script 2

Diferencia:
Utiliza if / else if / else. Cuando encuentra una condición verdadera, las siguientes ya no se ejecutan.
a = 950 if (a < 576) { console.log("xs") } else if (a < 768) { console.log("sm") } else if (a < 962) { console.log("md") } else { console.log("xl") }
Presiona el botón...

¿Qué los diferencia?

En el Script 1, los if son independientes. Por eso, si varias condiciones son verdaderas, se pueden ejecutar varias al mismo tiempo.

En el Script 2, las condiciones forman una sola cadena de if / else if / else. Solamente se ejecuta la primera condición que sea verdadera.

Como a = 950, en el Script 2 se cumple a < 962, por lo que muestra: md.
